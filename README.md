# FIT UP — Fitness Lifestyle

Landing page for **Fit Up Fitness Lifestyle** — Gym / Physical Fitness Center.
Fitness · Gym · Yoga · HIIT · Zumba · Personal Training.

Built with React 19, Vite, Tailwind CSS, GSAP and Three.js.





## Getting started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploy

This is a static Vite build (`dist/`) and deploys out of the box on [Vercel](https://vercel.com):

- Framework preset: **Vite**
- Build command: `npm run build`
- Output directory: `dist`
